# PinToDesk_edit

常驻 Windows 桌面的待办便签。用标签分开不同清单，用颜色标记条目；双击或右键即可编辑。主窗口留在其他应用下方。

原作者：**li5bo5** · [原项目地址](https://github.com/li5bo5/PinToDesk)

修改优化：**onixary** · [改版项目地址](https://github.com/onixary/PinToDesk)

## 下载与升级

从 [PinToDesk_edit 发布页](https://github.com/onixary/PinToDesk/releases) 下载 Windows x64 压缩包。推荐自包含版（SelfContained），解压后运行 `PinToDesk_edit.exe`。从旧版升级时，先从托盘退出，再把原 `Data` 文件夹复制到新版程序旁。

## ✨ 功能特点

- **Fluent 动态主题与磨砂质感**：支持「跟随系统（自动提取任务栏颜色与感知亮度）/ 浅色 / 深色」主题，支持 40% ~ 100% 窗口不透明度实时预览调节
- **桌面深度融合与 `Win + D` 免疫**：绑定桌面宿主 `Progman`（Explorer 重启自动重绑），非置顶状态下依然稳定常驻桌面之上，不被 `Win + D` 隐藏或遮盖
- **分类标签**：点击标题下的标签切换清单，右侧「＋」新建，双击标签名就地修改，右键删除前会确认。标签太多时，在标签栏上滚动滚轮即可横向浏览。
- **桌面便签**：其他应用可以盖住便签。双击托盘图标只切换桌面便签的显示与隐藏，不会把它提到前台。
- **统一新建与编辑体验**：双击空白处或点击右上角 `＋` 统一弹出居中编辑框；新建时点「确认」，编辑时点「保存修改」，也支持多行文本（`Shift + Enter` 换行）、`Enter` / `Ctrl + S` / **屏幕任意外部区域双击**快捷保存、编辑置空自动删除、Fluent 中文右键菜单
- **原生丝滑拖拽排序**：按住条目自由上下拖拽，支持平滑插槽避让动画与边缘自动滚屏
- **待办历史（回收站）**：删除待办自动归档至待办历史，支持单条原 ID 还原、彻底删除、清空历史及到期自动清理（默认保留 60 天，可自定义）
- **多显示器与混合 DPI 适配**：自由拖动跨屏零跳变，松手按连通多屏工作区超界自愈回弹；右下角拖拽缩放按物理像素严格钳制；自动记忆窗口尺寸与位置，外接显示器断开后启动自动复位
- **自研 Fluent 系统托盘与偏好设置中心**：极简 4 项托盘右键菜单（待办历史 / 偏好设置 / 关于 / 退出），二级窗口按需实例化、关闭彻底释放；单实例防多开拦截
- **绿色便携明文存储与熔断保护**：全部数据收敛于程序同级 `Data/` 目录（`.jsonl` 明文原子写盘 + 300ms 防抖异步落盘 + 读取异常熔断保护），老版本 `%AppData%\PinToDesk` 数据首次升级自动无损迁移

## 🖱️ 操作说明

| 操作 | 方法 |
|------|------|
| **新建待办** | 双击列表空白区域，或点击标题栏 `＋` 按钮 |
| **编辑待办** | 双击或右键单击待办项，修改文字后点击底部「保存修改」（清空内容保存视为删除） |
| **保存 / 取消编辑** | 新建点「确认」，编辑点「保存修改」；点「取消」放弃更改；`Enter`、`Ctrl + S` 或在输入框外任意位置双击保存；`Shift + Enter` 换行；`Esc` 取消 |
| **设置条目颜色** | 点击编辑弹窗底部色块即时预览，保存修改后保留；取消则恢复原色。白色斜线方块表示无色 |
| **删除待办** | 双击或右键单击待办项 → 点击编辑弹窗左下方「删除」（自动移入待办历史回收站） |
| **待办历史还原** | 右键托盘图标 → 「待办历史」→ 悬停条目点击 `⟲` 一键还原 |
| **拖拽排序** | 鼠标按住条目上下拖动，实时插槽避让并支持边缘自动滚屏 |
| **显示 / 隐藏便签** | 双击托盘图标；右上角「✕」也可隐藏 |
| **分类** | 标签栏右侧「＋」新建标签；双击名称修改，按 Enter 或点击标签外提交，Esc 取消 |
| **删除标签** | 右键标签 →「删除标签…」→ 确认。条目进入待办历史；恢复时优先回原标签，原标签已删除则放入当前标签 |
| **移动与缩放窗口** | 拖动标题栏自由跨屏移动（松手自动回弹防超界）；拖拽右下角手柄调整大小，最小 280 × 364 |
| **偏好设置** | 右键托盘图标 → 「偏好设置」（管理展开/3行折叠、主题、透明度、保留天数、开机自启与布局重置） |

## 💾 数据存储（绿色便携）

v2.0 起所有数据与配置文件统一存放在程序所在目录下的 `Data/` 文件夹中，不向系统散落文件，拷贝整个文件夹即可完整迁移：

| 文件名 | 用途说明 |
| :--- | :--- |
| **`Data/settings.jsonl`** | 统一偏好配置（主题、透明度、当前标签、窗口坐标尺寸、保留天数等） |
| **`Data/todos.jsonl`** | 升级前的清单，直接作为「默认」标签使用 |
| **`Data/tabs.jsonl`** | 标签名称和顺序 |
| **`Data/todos-<ID>.jsonl`** | 新建标签的独立清单；标签改名不改变文件名 |
| **`Data/recycle_bin.jsonl`** | 待办历史（回收站）数据文件 |
| **`Data/crash.log`** | 异常崩溃诊断日志（仅在发生异常时生成） |

> 💡 **老版本平滑升级**：从 PinToDesk v1.0.x 升级时，程序首次启动会自动读取 `%AppData%\PinToDesk\todos.md` 与 `settings.json` 并无损迁移至 `Data/` 目录（原文件保留不删）。

## 🚀 开机自启动

在系统托盘图标上右键 → 「**偏好设置**」→ 勾选「**开机时自动启动 PinToDesk_edit**」并保存即可。

> 提示：程序每次启动时会自动校准开机自启路径；若移动了 `.exe` 所在位置，运行一次新路径下的程序即可自动更新注册表路径。

## 🔧 从源码构建

```powershell
# 开发构建（门禁：0 警告 0 错误）
dotnet build PinToDesk_edit.csproj -c Release

# 发布（独立免装版，无运行库依赖）
dotnet publish PinToDesk_edit.csproj -c Release -r win-x64 --self-contained true -o "Publish\SelfContained_V2.1"

# 发布（框架依赖版，体积极小）
dotnet publish PinToDesk_edit.csproj -c Release -r win-x64 --self-contained false -o "Publish\FrameworkDependent_V2.1"
```

- 技术栈：C# / WPF / .NET 8
- 开源协议：**AGPL-3.0**
